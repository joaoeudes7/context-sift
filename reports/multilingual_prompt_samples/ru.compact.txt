Передача сеанса от модели Aurora к модели Boreal
Цель пользователя: устранить отклонение повторного использования токена обновления и добавить покрытие регрессии
Ограничение: не изменять публичный API или схему базы данных
Репозиторий находится в /workspace/identity
Расследование выявило гонку в src/auth/rotate_token.py: проверка и отмена действия являются отдельными транзакциями
Решение: использовать существующий метод репозитория rotate_atomically вместо добавления блокировки
Причина: метод уже выполняет compare-and-swap и работает между процессами
Завершено: воспроизведено сбои с tests/auth/test_rotation.py::test_concurrent_refresh; проверена история миграций; подтверждено, что изменение схемы не требуется
Неудачная попытка: локальная блокировка asyncio.Lock прошла для одного работника, но не прошла тест с несколькими работниками, поэтому была отменена
Ни один производственный файл не был отредактирован
Ожидание: пропатчить TokenService.refresh, чтобы вызвать rotate_atomically, сохранить аудиторское событие refresh.reuse_detected, затем выполнить pytest tests/auth/test_rotation.py -q

Соответствующая проблема: AUTH-417
Ожидаемое поведение: точно один одновременный запрос успешно завершается; остальные возвращают token_reused без недействительности нового токена
Не повторять расследование, если доказательства не противоречат
